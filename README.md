- # 🧠 Memory Flicker Game

A fun and interactive **Memory Flicker Game** built using **HTML, CSS, and JavaScript**.

Test your memory, find the matching pairs, and try to complete the game in the fewest moves possible! 🎮

## 🎮 How to Play

1. Click on a card to reveal its symbol.
2. Click on another card to reveal it.
3. If the two cards match, they stay revealed.
4. If they don't match, they flip back.
5. Continue until you find all the matching pairs.
6. Try to complete the game with the **fewest moves and in the shortest time!** ⏱️

## ✨ Features

- 🃏 Interactive card-flipping
- 🧠 Memory-based gameplay
- 🎨 Responsive and visually appealing design
- 🔄 Restart / New Game option
- 📊 Move counter
- ⏱️ Timer
- 🎉 Winning message when all pairs are matched
- 📱 Responsive design for different screen sizes

## 🛠️ Technologies Used

- **HTML5** – Structure of the game
- **CSS3** – Styling, animations and responsive layout
- **JavaScript** – Game logic, card matching and interactions
